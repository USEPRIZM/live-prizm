# Project Prizm: Technical Brief
**Mission:** Unblind the data.
**Product:** A visual, no-code sandbox for backtesting Nifty, stocks, and Crypto.

## Tech Stack
- **Frontend:** Next.js (App Router), Tailwind CSS, Lucide React (icons).
- **Backend/Data:** Python (FastAPI or Flask), Pandas, Yfinance/CCXT.
- **Aesthetic:** Minimalist, White background, Light Purple (#D0BDF4) & Deep Purple (#8B5CF6).

## Phase 1 Goals
1. Scaffold Next.js with the brand theme.
2. Create a Python script to fetch historical Nifty 50 data.
3. Build a simple "Chart" component to visualize that data.
